# metacodex 1.0.4

Restores accented input in macOS terminals and coding agents.

[Português](https://github.com/victorbenazzi/metacodex/blob/v1.0.4/docs/releases/v1.0.4.pt-BR.md)

## Bug fixes

- Fixes accented characters disappearing during keyboard composition on macOS.
- Preserves the text until the terminal finishes reading the committed character. Applies to both shell terminals and coding agents.
- Keeps the existing Linux and Windows input behavior.

Validated with native macOS WebKit and the Brazilian Pro keyboard layout, including words such as `ação` and `não`, uppercase letters and consecutive accents.

## Download and update

Packages are available for macOS Apple Silicon and Intel, Windows x64, and Linux x64 (`metacodex_1.0.4_amd64.deb` and `metacodex-1.0.4-1.x86_64.rpm`). Signed updater artifacts and `latest.json` are published after the release checks succeed.

Existing projects and settings are preserved. macOS builds use the project's self-signed identity and are not notarized. Windows builds are unsigned. See the [installation guidance](https://github.com/victorbenazzi/metacodex/blob/v1.0.4/README.md) if the operating system blocks a downloaded installer.
