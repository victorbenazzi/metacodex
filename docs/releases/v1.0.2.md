# metacodex 1.0.2

Version 1.0.2 is a Linux-only patch release focused on terminal input, native window integration and package reliability. No new macOS or Windows artifacts are published with this version.

[Leia estas notas em Português do Brasil](https://github.com/victorbenazzi/metacodex/blob/main/docs/releases/v1.0.2.pt-BR.md)

## Linux fixes

- Accented characters typed through WebKitGTK dead keys now reach terminal agents exactly once. The terminal clears stale composition input and suppresses duplicate synthetic events without interfering with screen reader mode or ordinary IME commits.
- The native Linux title bar is replaced by metacodex chrome. Minimize, maximize and close controls now use the active theme while macOS keeps its native traffic lights and Windows keeps the same custom-control behavior.
- External URLs and authorized project files use `xdg-open`, with `gio open` as a fallback for GTK desktops.
- PTY sessions preserve desktop environment variables needed for X11, Wayland, D-Bus and the active session.
- Linux packages ship a validated desktop entry, declare `xdg-utils` as a recommended dependency and register the supported file types correctly.
- The release pipeline smoke-tests the installed Debian package on Ubuntu and the installed RPM package on Fedora before publishing.

This release intentionally contains no new macOS or Windows installers. Their latest published version remains 1.0.1.

## Updating from 1.0.1

The Linux in-app updater selects the package format currently installed and delegates installation to the system package flow with elevated privileges. Manual `.deb` and `.rpm` downloads remain available from this release page. Configuration and workspace state under `~/.metacodex` are unchanged.

## Release qualification

- Full frontend test suite, TypeScript check and production build.
- Rust formatting, Clippy, checks and unit tests.
- Cross-platform quality checks to protect the shared codebase.
- Native WebKitGTK tests under Xvfb and D-Bus.
- Installed-package smoke tests on Ubuntu 22.04 and Fedora.
- Signed updater metadata validation for both `.deb` and `.rpm`.
