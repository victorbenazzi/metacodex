# metacodex 1.0.3

Agent usage visibility, safer file saves and more reliable terminal sessions.

[Português](https://github.com/victorbenazzi/metacodex/blob/v1.0.3/docs/releases/v1.0.3.pt-BR.md)

## Agent usage

- New usage panel for available Codex, Claude, Cursor and Grok data, with account quotas, local session counters and history where supported.
- Optional account connections and per-agent collection controls. Missing data is identified rather than shown as zero.
- Improved workspace resizing and source-control interactions.

## Bug fixes

- Failed editor saves remain visible and block normal quit instead of silently dropping changes.
- Native quit and update restart use the shutdown coordinator. Unix terminal cleanup handles child processes and includes a guardian for abrupt application termination.
- Cancellation during startup waits for cleanup ownership to finish.
- Missing retained terminal output becomes a recoverable stream error. Partial event-listener installation is rolled back before retry.
- Browser captures retain their original agent destination while capture is in progress.
- Atomic saves preserve executable permissions.
- Server stop reports failure when a process ignores termination. Linux process ownership checks now use the process table.
- Completed terminal tabs no longer prevent resuming a session.
- Includes the Linux input, window controls and desktop integration fixes from 1.0.2.

## Download and update

This release publishes macOS Apple Silicon and Intel, Windows x64, and Linux x64 packages (`metacodex_1.0.3_amd64.deb` and `metacodex-1.0.3-1.x86_64.rpm`). Signed updater artifacts and `latest.json` are published after the release checks succeed.

Configuration and projects remain in the existing application data directory. Account connections are optional. Availability of quota and history data depends on each provider.

macOS builds use the project's self-signed identity and are not notarized. Windows builds are unsigned. See the [installation guidance](https://github.com/victorbenazzi/metacodex/blob/v1.0.3/README.md) if the operating system blocks a downloaded installer.
