# metacodex 1.0.4

Corrige a acentuação nos terminais e agentes de código no macOS.

[English](https://github.com/victorbenazzi/metacodex/blob/v1.0.4/docs/releases/v1.0.4.md)

## Correções

- Corrige o desaparecimento de caracteres acentuados durante a digitação no macOS.
- Preserva o texto até o terminal concluir a leitura do caractere composto. A correção vale para terminais de shell e agentes de código.
- Mantém o comportamento de entrada existente no Linux e no Windows.

Validado no WebKit nativo do macOS com o teclado Brasileiro Pro, incluindo palavras como `ação` e `não`, letras maiúsculas e acentos consecutivos.

## Download e atualização

Pacotes disponíveis para macOS Apple Silicon e Intel, Windows x64 e Linux x64 (`metacodex_1.0.4_amd64.deb` e `metacodex-1.0.4-1.x86_64.rpm`). Os artefatos assinados do atualizador e o arquivo `latest.json` são publicados após as verificações da release.

Projetos e configurações existentes são preservados. Os builds de macOS usam a identidade autoassinada do projeto e não são notarizados. Os builds de Windows não são assinados. Consulte as [instruções de instalação](https://github.com/victorbenazzi/metacodex/blob/v1.0.4/README.pt-BR.md) se o sistema bloquear o instalador baixado.
