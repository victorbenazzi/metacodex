# metacodex 1.0.3

Visibilidade de uso dos agentes, gravação de arquivos mais segura e sessões de terminal mais confiáveis.

[English](https://github.com/victorbenazzi/metacodex/blob/v1.0.3/docs/releases/v1.0.3.md)

## Uso dos agentes

- Novo painel com os dados disponíveis de Codex, Claude, Cursor e Grok: cotas de conta, contadores de sessões locais e histórico quando oferecido pelo provedor.
- Conexões de conta opcionais e controles de coleta por agente. Dados indisponíveis são identificados, sem apresentar zero como resultado.
- Melhorias no redimensionamento do workspace e nas interações de controle de versão.

## Correções

- Falhas ao salvar no editor ficam visíveis e impedem o encerramento normal, evitando a perda silenciosa de alterações.
- O encerramento nativo e a reinicialização para atualizar passam pelo coordenador de saída. A limpeza de terminais Unix encerra processos filhos e inclui um processo guardião para a morte abrupta do aplicativo.
- O cancelamento durante a inicialização aguarda o responsável pela limpeza.
- Lacunas no histórico de saída do terminal geram erro recuperável. A instalação parcial de listeners é desfeita antes de uma nova tentativa.
- Capturas do navegador preservam o agente de destino escolhido no início da operação.
- A gravação atômica preserva permissões de execução dos arquivos.
- A parada de servidor informa falha quando o processo ignora o sinal de encerramento. A verificação de processos no Linux utiliza a tabela de processos.
- Abas encerradas deixam de impedir a retomada de sessões.
- Inclui as correções de entrada de texto, controles de janela e integração desktop do Linux na versão 1.0.2.

## Download e atualização

Esta versão publica pacotes para macOS Apple Silicon e Intel, Windows x64 e Linux x64 (`metacodex_1.0.3_amd64.deb` e `metacodex-1.0.3-1.x86_64.rpm`). Os artefatos assinados do atualizador e o arquivo `latest.json` são publicados após as verificações da release.

Configurações e projetos permanecem no diretório de dados existente. A conexão das contas é opcional. A disponibilidade de cotas e histórico depende de cada provedor.

Os builds de macOS usam a identidade autoassinada do projeto e não são notarizados. Os builds de Windows não são assinados. Consulte as [instruções de instalação](https://github.com/victorbenazzi/metacodex/blob/v1.0.3/README.pt-BR.md) se o sistema bloquear o instalador baixado.
