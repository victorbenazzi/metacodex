# metacodex 1.0.2

A versão 1.0.2 é uma correção publicada somente para Linux, focada na entrada do terminal, integração nativa da janela e confiabilidade dos pacotes. Nenhum artefato novo para macOS ou Windows é publicado nesta versão.

[Read these notes in English](https://github.com/victorbenazzi/metacodex/blob/main/docs/releases/v1.0.2.md)

## Correções no Linux

- Caracteres acentuados digitados por teclas mortas do WebKitGTK agora chegam aos agentes no terminal uma única vez. O terminal limpa entradas antigas da composição e suprime eventos sintéticos duplicados sem interferir no modo de leitor de tela ou em commits normais de IME.
- A barra de título nativa do Linux foi substituída pelo chrome do metacodex. Os controles de minimizar, maximizar e fechar agora usam o tema ativo, enquanto o macOS mantém seus traffic lights nativos e o Windows preserva o mesmo comportamento dos controles personalizados.
- URLs externas e arquivos autorizados dos projetos usam `xdg-open`, com `gio open` como fallback nos desktops GTK.
- As sessões PTY preservam variáveis do ambiente gráfico necessárias para X11, Wayland, D-Bus e a sessão ativa.
- Os pacotes Linux incluem uma entrada de desktop validada, declaram `xdg-utils` como dependência recomendada e registram corretamente os tipos de arquivo suportados.
- O pipeline de release testa o pacote Debian instalado no Ubuntu e o pacote RPM instalado no Fedora antes da publicação.

## Download

| Plataforma | Artefato |
| --- | --- |
| Debian e Ubuntu x64 | `metacodex_1.0.2_amd64.deb` |
| Fedora e distribuições RPM x64 | `metacodex-1.0.2-1.x86_64.rpm` |

Esta release não contém instaladores novos para macOS ou Windows. A versão mais recente publicada para esses sistemas continua sendo a 1.0.1.

## Atualizando a partir da 1.0.1

O updater interno no Linux seleciona o formato do pacote instalado e delega a instalação ao fluxo de pacotes do sistema com privilégios elevados. Os downloads manuais de `.deb` e `.rpm` continuam disponíveis nesta página da release. A configuração e o estado dos workspaces em `~/.metacodex` não mudam.

## Qualificação da release

- Suíte completa de testes do frontend, verificação de TypeScript e build de produção.
- Formatação Rust, Clippy, checks e testes unitários.
- Verificações de qualidade entre plataformas para proteger a base compartilhada.
- Testes nativos do WebKitGTK com Xvfb e D-Bus.
- Smoke tests dos pacotes instalados no Ubuntu 22.04 e Fedora.
- Validação dos metadados assinados do updater para `.deb` e `.rpm`.
